# WA manual installation locations

The ZIP root contains folder structure relative to `wonderfulApp/`. Install the files in `standard/` into the existing `wonderfulApp/standard/` folder. Install the `.diff` files and verification `.md` in the existing `wonderfulApp/change/` folder. Do not place any of these files in the project root.

No `routes/` or application source file is part of this package. Existing `DRAFT` filenames are retained intentionally for link compatibility.

No project files were modified by the assistant.
