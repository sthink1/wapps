FINDING
The final upload error middleware used /Only JPG/.test(err.message || '') to classify any
exception as expected HTTP 400 input validation. An unforeseen exception containing that
phrase could disclose internal error text to authenticated clients.

CHANGES
- Only errors generated by the actual Multer fileFilter are marked as expected upload
  validation errors through a private module-local WeakSet.
- Keep exact user message 'Only JPG, PNG, and WEBP images are allowed.' and HTTP 400.
- Keep MulterError HTTP 400 responses and their existing messages, including size limit.
- Forward unrelated exceptions to the existing downstream error handling.
- Preserve the 10 MiB file-size limit, memoryStorage, accepted MIME types, upload and
  image/R2 workflows and all other Family Tree routes.
- No database statements or environment changes.
