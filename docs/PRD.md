# FamilyTree - Product Requirements Document

**Version:** 1.0  
**Date:** May 9, 2026  
**Status:** Planning

## 1. Executive Summary

FamilyTree is a genealogy and family tree management application being converted from Microsoft Access into a Wonderful Apps module.

## 2. Goals & Scope

### Core Objectives

1. Convert the Access application to a web-based Wonderful Apps module
2. Preserve core family tree and genealogy functionality
3. Maintain data integrity during migration
4. Provide a modern, web-based user interface
5. Integrate seamlessly with Wonderful Apps infrastructure

## 3. Data Model

- People/Persons
- Events (birth, death, marriage, etc.)
- Relationships (family links)
- Contacts
- Pictures/Media
- Notes and sources

## 4. High-Level Architecture

Key principle: **Backend handles data logic and storage, frontend provides web-based user interface.**

## 5. Deployment

FamilyTree will be deployed as a module within the Wonderful Apps project infrastructure.
