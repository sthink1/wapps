WONDERFUL APPS USAGE

App Usage

App Usage is the primary view for comparing how each Wonderful Apps application is being used. The measurements are intended to help relate application activity to hosting, database, email, bandwidth and storage costs. Storage Activity currently counts file uploads; it does not yet measure bytes stored.

User Usage

Select a user from the list or enter a UserID. User Usage has its own period filter, independent of the App Usage period above.

Free Tier Usage

This section compares current Wonderful Apps service usage with the free-tier limits that matter to the present WA setup. Database size and Resend email volume are retrieved automatically. Current R2 stored data is measured from the configured bucket. Render instance hours and R2 operation totals remain provider-dashboard values until those provider metrics are connected. The Next Paid Level and Cost columns show the immediate fallback if a free allowance is reached, helping plan an upgrade before service is interrupted. x10 is not included because WA now sends through Resend and Contact Us is delivered to Gmail.

Status thresholds: under 70% = OK; 70% through 84.9% = Caution; 85% and above = Warning. Provider means the current value must be read from that provider's dashboard. R2 storage is shown as current stored bytes against the 10 GB-month free allowance, so it is a useful capacity indicator rather than the provider's final monthly billing calculation. Paid-level prices are planning references; check the provider before upgrading because pricing can change.
