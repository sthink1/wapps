UNDO ONE TREE MERGE

Use this only when two Family Trees were combined by mistake.

Undo restores the newer Tree and its original FamilyTreeCode. It does not restore an old database backup. The system separates the Trees using the merge snapshot captured when the One Tree merge was completed.

If several One Tree merges were performed, the newest dependent merge must be undone first.
